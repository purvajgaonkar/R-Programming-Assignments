The 12 source images live here:
  p1.jpg .. p6.jpg   planes
  c1.jpg .. c6.jpg   cars

If this folder is empty, the first script generates them from CIFAR-10
(class 0 = airplane, class 1 = automobile).

To use your own photographs instead, place 12 images here with exactly
these names before running. The script will detect them and skip generation.
